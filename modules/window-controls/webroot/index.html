Features

Settings are saved across reboots. Reopen a window’s menu after applying. Temporary root must be active.

Home supports up to 50 pinned apps while this module is running. Above 10, scroll vertically through the same five-column tile grid.

After a Soft restart, controls wait until SystemUI is 90 seconds old; borderless attaches 45 seconds later. Reopen app windows afterward.

If the runtime is quarantined, use the existing full reboot recovery procedure before starting it.
