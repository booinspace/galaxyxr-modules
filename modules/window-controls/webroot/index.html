Features

Settings are saved across reboots. Reopen a window’s menu after applying. Temporary root must be active.

Home supports up to 50 pinned apps while this module is running. Above 10, scroll vertically through the same five-column tile grid.

Controls wait until SystemUI is 90 seconds old; borderless attaches 45 seconds later. Reopen app windows afterward.

Enabled Window Controls starts automatically after a KernelSU GXR Soft restart. Action remains available for settings and logs.
