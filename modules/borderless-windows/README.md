# Borderless window component

The supported Home Space window setup is the
[combined Window Controls module](../../docs/CURVATURE.md), which supplies
rim hiding, hover-only caption, curvature and rotation through one runtime.
Keep this independent component disabled beside the combined module.

The sources here provide the standalone agent and service controller used by
component build tooling. The shared runtime uses
[`scripts/curvature-borderless-agent.mjs`](../../scripts/curvature-borderless-agent.mjs).
For current installation, use, builds and recovery, follow the
[combined guide](../../docs/CURVATURE.md). Runtime component notices are in
[THIRD_PARTY.md](THIRD_PARTY.md).
